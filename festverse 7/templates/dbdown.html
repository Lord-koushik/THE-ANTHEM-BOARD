The Anthem Board stores everything in PostgreSQL, and the app couldn't reach a server. Pick whichever option is easiest:

Option 1: no install (recommended)

pip install -r requirements-local.txt

This downloads a small embedded PostgreSQL into the project folder, starts it, builds the tables and loads demo data automatically.

Option 2: Docker

docker compose up -d
python app.py

Option 3: your own PostgreSQL (Mac with Homebrew)

brew install postgresql@16 && brew services start postgresql@16
psql postgres -c "CREATE USER fest WITH PASSWORD 'fest' SUPERUSER;"
psql postgres -c "CREATE DATABASE festverse OWNER fest;"
python app.py
